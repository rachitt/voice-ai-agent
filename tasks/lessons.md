# Lessons

Append-only mistakes log. Keep <300 lines (CLAUDE.md §2). Read at start of every session.

## 2026-05-11

- TS 6 deprecates `baseUrl` in tsconfig. Path aliases work without it via `paths` alone when `moduleResolution: "bundler"`. Don't add `baseUrl` to new Vite scaffolds.
- Tailwind v4 uses `@import "tailwindcss"` + `@theme { --color-* }` block — no `tailwind.config.ts` needed for tokens.
- React Flow v12 needs explicit generic: `<ReactFlow<StepNode> ... />`, else `onNodesChange` widens to `Node` and breaks the store handler.
- React StrictMode double-mounts effects. Streaming-from-index patterns with a local `let i = 0` produce duplicate or out-of-bounds reads. Compute next index inside `setState` updater from existing array length + dedupe by id.
- Vite default port 5173 is shared across worktrees on this machine — another project's SvelteKit dev server squats on it. Vite auto-falls-back to 5174. Either accept that or pin a unique port in `vite.config.ts`.
- Always verify UI in browser before claiming done — build-clean ≠ runtime-clean. The first console render had an uncaught TypeError despite `pnpm build` passing.
- structlog reserves the kwarg name `event` — passing `event=...` to `log.info(...)` raises `got multiple values for argument 'event'`. Use `event_type=` or any other key.
- Async SQLAlchemy: after `session.expire_all()`, accessing `obj.id` triggers a sync lazy-load that errors with `MissingGreenlet`. Capture primary keys into local vars (`row_id = row.id`) before the expire.
- Adding a child row that FKs back to a parent in the same commit needs an `await db.flush()` between `db.add(parent)` and `db.add(child)`, otherwise the child sees `parent.id = None` and Postgres rejects with `NotNullViolation`.
- `audioop-lts` PyPI package installs under the module name `audioop`, so `import audioop` works on 3.11/3.12 (stdlib) and 3.13+ (LTS shim) with no branching. Declare it as `audioop-lts>=0.2.2; python_version>='3.13'` and silence the 3.11 deprecation via `warnings.filterwarnings` around the import.
- Vite 8 with Rolldown bundler — `build.rolldownOptions.output.manualChunks` only accepts a **function** `(id) => 'name'`, not the Rollup-style `{name: [pkgs]}` object form. The latter type-errors at build.
- Pipeline `on_turn_end` callbacks used to deadlock when calling `await pipe.close()` — close awaited `cancel_current_turn`, which was the calling task. Fixed at the root in `Pipeline.cancel_current_turn`: detect `asyncio.current_task() is self._turn_task` and skip the `await t`, just `t.cancel()`. Callers now just `await pipe.close()` from anywhere.
- For bugs: fix at the root cause, not at the call site. If a callback can't safely call API X, the bug is in X — make X safe. Workarounds (scheduling on background tasks, marker flags) add new failure modes (orphan tasks, lost exceptions, ordering races) and force every caller to remember the rule. Per CLAUDE.md: "dont just scratch the surface."
- Flow-graph `condition` nodes classify against the **already-completed** turn — entering a condition node must run the classifier synchronously and route immediately. Waiting for a second user turn would never fire because the agent hasn't said anything to prompt one.
- FastAPI query params named after Python builtins (`range`, `id`, `type`) shadow the builtin inside the function body — `for i in range(...)` raises `TypeError: 'str' object is not callable`. Either pick a different param name or use `Query(... alias="range")` with an underscored arg (e.g. `range_: str = Query("7d", alias="range")`).
- Recharts v3 tooltip `formatter` is `(value: ValueType | undefined, name: NameType) => ReactNode`. Annotating `(v: number, name: string)` will fail tsc — drop the param types and coerce inside.
- SQLAlchemy JSON path indexing for Postgres JSONB: `Call.analysis[("success_evaluation", "success")].astext` materializes nested keys as text. Compose into `case((expr == "true", 1), ...)` for cheap aggregation without round-tripping JSON to Python.
- Playwright `getByText('xyz')` is non-exact by default — partial substring matches anywhere. If the same string appears as both a name and inside a URL, use `getByText('xyz', { exact: true })` or scope under a `data-testid` ancestor.
- For long-lived assets behind bearer auth (recordings, exports), prefer minting a short-lived presigned URL via the API and letting the browser fetch directly. Streaming through the API proxy works but doesn't scale past dev — and `<audio>`/`<video>` elements can't attach `Authorization` headers anyway.
- GitHub Actions workflows alone do NOT block pushes — branch protection has to be configured server-side (Settings → Branches). A `required:` aggregate job that depends on all real jobs makes branch protection setup a single checkbox instead of N. Pair w/ a local `core.hooksPath=.githooks` pre-push hook for the laptop-side experience.
- `alembic check` can flag legitimate drift (e.g. `use_alter=True` FKs that intentionally skip the create-table migration) as well as bugs. Treat it as a "soft gate" until the repo is at a known-clean baseline, then flip to required. Same playbook for mypy + eslint when the codebase isn't fully typed/linted yet.
- Coverage attribution under FastAPI tests needs `concurrency = ["thread", "greenlet"]` in `[tool.coverage.run]`. `AsyncClient + ASGITransport` runs route bodies via anyio task groups (threads); SQLAlchemy async runs in greenlets. Default `thread`-only setup undercounts route+ORM code by ~20pts. Set both.
- WS route tests via `TestClient(create_app())` run in a separate thread/loop from the test fixture's `db_engine`. Sharing the fixture's sessionmaker triggers `Future attached to a different loop`. Pattern: `LoopBoundSessionLocal(url)` that lazily builds `(engine, sessionmaker)` keyed by `id(asyncio.get_event_loop())` and monkeypatches the router-local `SessionLocal` name.
- `parseApiError` double-space bug: error strings like `"Error: 422  {…}"` arrived with a double space after the status code. The regex was `/^Error:\s\d+\s/` (single space) so the JSON capture missed. Match `\s+` between tokens to survive both formatter and double-space variants. Caught by vitest, never by the e2e.
- LiteLLM Gemini routing: bare `gemini-X.Y-flash` model id routes to Vertex AI (needs `google-cloud-aiplatform` + ADC). For AI Studio, the model id must be prefixed `gemini/` (e.g. `gemini/gemini-3.1-flash-lite`). Defaults that ship without the prefix silently break voice agents at first turn.
- ElevenLabs config has two slots: `voice_id` (a 20-char like `21m00Tcm4TlvDq8ikWAM`) and `model_id` (like `eleven_flash_v2_5`). Conflating them — defaulting `agent.voice_id` to a model id — causes `voice_id_does_not_exist` at TTS. Keep them distinct; default voice = Rachel `21m00Tcm4TlvDq8ikWAM`.
- For end-to-end voice loop testing without a mic: macOS `say -o file.wav --data-format=LEI16@16000 "text"` produces PCM the web-call WS accepts directly. Stream as 20ms binary frames (640 bytes @ 16kHz mono LE16), pad with ~1s of zeros to flush Deepgram's interim → final.
- Storing API keys in `localStorage` is an XSS-extractable credential — never do this for a dashboard. Right pattern: a one-time `POST /v1/auth/session/api-key` exchanges the key for an httpOnly+SameSite=Lax session cookie (same shape as OAuth's), then every fetch goes with `credentials: 'include'` and the localStorage key is never touched again. The unified `require_principal` dep on the backend accepts EITHER the cookie (dashboard) OR Bearer (external SDKs), so the same routes serve both consumers without forking auth.
- Cross-origin dev (web:5174 → api:8000) drops SameSite=Lax cookies on every XHR — the user looks signed in but every API call 401s. Fix: vite proxy `/v1/*` to the API so the browser treats it as same-origin. Don't proxy WebSockets through vite 8 though — its WS upgrade EPIPEs under any load. Bypass by injecting `__VITE_API_ORIGIN__` via `define` and pointing WS direct to the API host. WS auth is already covered by the HMAC `ws_token` query param, no cookie needed.
- ElevenLabs `ElevenLabsStream.audio()` quietly returning on error frames is the worst-kind-of-bug: LLM keeps streaming `agent_text` while the user hears nothing. Raise a typed exception (`TtsProviderError`) so the orchestrator can emit a dedicated `tts_error` PipelineEvent and the UI can surface a banner ("TTS provider error: quota_exceeded"). Silent failure → loud failure.
- TTS char cost goes mostly to repeat strings (`first_message`, flow-node prompts). Redis-cache PCM by sha256(`voice_id|tts_model|sample_rate|text`) before synth — same inputs produce byte-identical waveforms, so it's a clean key. 30d TTL, 4MB cap per value, silent on Redis failure (fall through to real synth). Big win on dev: every reload of a builder hits the same greeting and burns the same 200+ credits otherwise.
- Custom tools (DB-backed `Tool` rows) were silently dropped on web-call WS: `_resolve_tools` only looked at REGISTRY built-ins, and `tool_dispatch` rejected anything not in REGISTRY. Result: a "create_calendar_event" tool would appear in the agent schema (if the LLM was lucky enough to see it via the raw-dict path) but never actually POST to `server_url`. Fix: query `Tool` by id at config-build time, translate `params_schema` into an OpenAI function schema, and add an HTTP dispatcher branch that POSTs `tc.arguments` to `row.server_url` with `row.timeout_ms`/`row.headers`. Apply to both `web_call_ws.py` and `telnyx_media_ws.py` so PSTN calls behave identically.

## 2026-05-13

- SameSite=Lax cookies stop *cross-site* CSRF but NOT same-site (sibling subdomain, compromised first-party iframe). Closing the gap: double-submit-cookie. Server mints a high-entropy CSRF token, stores it in a non-httpOnly cookie alongside the session cookie. JS reads the cookie and copies it into an `X-CSRF-Token` header on POST/PUT/DELETE. Middleware compares the two via `secrets.compare_digest`. Bearer-API-key callers skip the check (not browsers, no victim cookie to ride). Webhooks + login endpoints go on an exempt list so the bootstrap path still works. Tests that issue session-cookie writes need a `{cookie: voice_csrf, header: x-csrf-token}` pair.
- `pipe._speak` swallowed `TtsProviderError` then *fell through* to `tts_cache.put_pcm`, caching a partial waveform whenever the provider broke mid-utterance. Next call replays the truncated audio forever. Fix at the root: add `return` after emitting `tts_error`, so cache writes only happen on full successful synth. Same shape as the `except Exception` path which already returned.
- TTS-cache savings only become real if measured. Per-call counter on `Pipeline` (`{hits, misses, miss_chars}`), stashed onto `call.dynamic_variables["tts_cache"]` at finalisation, plus a `tts_cache.summary` structlog line. `miss_chars` is the dollar number — ElevenLabs bills per char. WS test fakes that don't inherit Pipeline need `getattr(pipe, "tts_stats", None)` in the router so the existing FakePipeline mocks don't trip an AttributeError.
- Session JWT secret should be distinct from the webhook HMAC secret so they rotate independently. New `session_secret` setting falls back to `webhook_hmac_secret` when empty (backwards-compat for envs not yet rotated). Rotating webhook HMAC no longer logs everyone out; rotating session secret does (intentionally — that's the "kill all sessions" lever).
- For `--cov-fail-under` strict gates: display rounds (94.85% → "95%") but pytest enforces a hard `>= N`. To clear 95 you need 95.00% minimum, which means a ~5-line cushion in a 4k-LOC codebase. Coverage doesn't have to come from new tests — removing genuinely-dead code (e.g. `require_api_key` that no router imports) shrinks the denominator and bumps the percentage with zero risk.
- Service-account Google auth without `google-auth`: sign an RS256 JWT with `jose.jwt.encode` using the SA private key, POST to `oauth2.googleapis.com/token` with `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer`, cache the `access_token` until ~60s before `expires_in`. Adds zero new deps (`python-jose[cryptography]` is already in for session JWTs) and the entire flow is `httpx.MockTransport`-testable. Retry once on 401 with `force_refresh=True` to ride out token revocation / clock skew without dropping the call.
- ElevenLabs free-tier blocks API access to "library voices" (Rachel `21m00Tcm4TlvDq8ikWAM` is one). TTS endpoint returns 402 `paid_plan_required`. Premade voices like Sarah `EXAVITQu4vr4xnSDxMaL` ARE accessible. Default voice in any open-source build should be a premade so dev/demo accounts work out of the box. Defaults live in 6 places: `orchestrator.AgentConfig`, `schemas.AgentSettingsIn`, `models.AgentVersion`, `routers/catalog._VOICES`, `web/NodeInspector.VOICE_FALLBACK`, plus DB rows for existing agents (one bulk UPDATE).
- LLMs hallucinate success on tool actions when no tool is bound: "Done, I booked it" with zero `tool_result` in the transcript. Root cause is structural — system_prompt alone can't enforce "you MUST call the tool". The fix is the **Retell/Vapi pattern**: bind tools per-state, not per-agent, and use a `slot_fill` node that loops in-place until every required slot is in the var bag. Auto-bind `extract_data` builtin on slot_fill nodes regardless of agent-level config so the LLM has somewhere to persist what it learned.
- Per-node tool overrides: mutate `cfg.tools` on each `_enter` so the next LLM turn sees the right subset. Stash the agent-level `_base_tools` once at construction; "no override" = restore from base, "override = [names]" = intersect with base + add `ensure` builtins. `cfg.tools` is read fresh per LLM call so in-place mutation is the cheapest hook point.
- `tool_call` flow node lifecycle messages (Vapi pattern): `pre_message` ("Let me check…"), `success_message` ("Done!"), `error_message` ("I had trouble…") map to the same three events Vapi exposes. The error_message slot doubles as a **route gate** — pair with a labelled `error` outbound edge so the executor can fall back to a transfer/voicemail when the tool fails.
- N-way NL transition classifier (Retell pattern): edges carry `data.condition` text; when > 1 outbound edge exists, ask the LLM to "Reply with the number only" against a numbered list of conditions. Parse first integer, range-check, fall back to first outbound on any failure. Single-outbound edges skip the classifier (no extra LLM cost) so simple flows stay fast.
- For backwards-compat when extending tuples in shared data structures (e.g. `_edges[src]` from `(target, label)` → `(target, label, condition)`), search tests for any direct tuple comparison and update in lock-step. Mypy doesn't catch this — it's hidden inside `dict[str, list[tuple[...]]]` declarations where the test asserts a literal.
- For "users connect their own Google Calendar from inside the app", the right shape is per-org **OAuth authorization-code flow with `access_type=offline` + `prompt=consent`** so Google always returns a `refresh_token`. Store `{org_id, provider, refresh_token, access_token, expires_at}` in `OAuthIntegration`. Adapter mints fresh access tokens on demand from the refresh_token. The app operator still has to provision **one** Google OAuth client (client_id + secret) in GCP Console — but every end-user then connects through it, not through their own GCP project. Per-org row is upserted, so re-connecting cleanly replaces stale creds.
- OAuth callback paths must be exempt from CSRF middleware (the third-party IdP doesn't carry your `X-CSRF-Token` header). The state-cookie/state-param compare-digest pair plays the same role for these endpoints. Add the exact callback path prefix to `CSRF_EXEMPT_PREFIXES`.
- **WORKFLOW RULE — never commit directly to `main`.** CLAUDE.md §3: branch per feature → PR → review → merge. Committed 12 commits direct to main this session and only caught it when GitHub push-protection blocked a leaked secret. Always: (1) `git checkout -b feat/<name>` BEFORE the first commit of a feature, (2) keep commit subjects short (<60 chars), (3) `gh pr create` once done. Reset-and-rebranch after the fact is painful when filter-repo also has to run.
- **NEVER hardcode secrets, even as `||` fallbacks.** Pattern `process.env.API_KEY || 'sk_live_…'` in a demo script still counts as a leak — GitHub's push-protection scanner blocks the push and indexes the value. Always make env vars required + exit with a clear error when missing. To scrub after the fact: `git filter-repo --replace-text rules.txt --force`; note filter-repo drops the origin remote as a safety check, so re-add it deliberately afterward.
